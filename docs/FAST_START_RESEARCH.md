# Старт за 5 минут: чего не хватает пайплайну и что взять с GitHub (26.11.2026)

## Почему бюджеты сгорают за 1-2 дня

Кампании Movie Trailer на promote.fun ($6 400 и $2 160) выбрали за двое суток, Popular Meme ($12 000) тоже.
Это команды с готовым конвейером: кампания вышла, через минуты у них уже выложены ролики на десятках аккаунтов.
На GitHub такие конвейеры есть в открытом виде (ниже), значит это норма рынка.

## Где мы теряем время сейчас

| Шаг | Как сейчас | Задержка |
|---|---|---|
| Узнать о кампании | сторож promote.fun раз в 15 мин | до 15 мин |
| Вступить в кампанию | вручную; страницы одобряет клиент | минуты, часы |
| Достать контент | вручную скачать из брифа (MediaSilo, Drive), вписать в config | 10-30 мин |
| Нарезка | таймер `kick` раз в 3 часа | **до 3 часов** |
| Хуки | ждут `clip-approve` | пока человек не ответит |
| План | `clip-plan` раз в час, 1 пост в день на аккаунт, 3 часа между постами | **до суток** |
| Публикация | 1 браузер за раз, ~2-3 мин на пост; 45 аккаунтов = ~2 часа | **часы** |
| Сабмит | ссылки вставляются руками в кабинете площадки | минуты, часы |

Итого от выхода кампании до первых 45 роликов сейчас уходят сутки, у конкурентов минуты.

## Что добавить (по выигрышу)

1. **Режим «горячая кампания» одной командой.** `campaign-go <ссылка на контент> --campaign ...`:
   скачать, нарезать, хуки без ожидания одобрения (или одобрение одной кнопкой в Telegram), план сразу на все
   подходящие аккаунты без окна и пауз в 3 часа, публикация немедленно. Нарезка не ждёт таймер.
2. **Параллельная публикация:** 3-4 профиля AdsPower одновременно вместо одного (сейчас глобальная блокировка).
   45 постов за ~30 мин вместо ~2 часов. Сервер (6 ядер, 12 ГБ) это тянет.
3. **Кнопки в Telegram** на уведомление сторожа: «Запустить» (campaign-go) и «Одобрить все хуки».
4. **Сабмит автоматически:** браузер с вашим входом в clipping.net / promote.fun вставляет ссылки сам, сразу
   после публикации. Сейчас это ручной шаг, а окно сабмита ограничено.
5. **Быстрая нарезка (идея NeonClipping):** для YouTube брать готовые субтитры YouTube вместо распознавания,
   качать только аудио, а видео только выбранных кусков. Длинный эфир за 1-2 минуты вместо 10.
6. **Субтитры по словам на видео.** У всех сильных клипперов (OpenShorts, SupoClip, NeonClipping, AutoClip)
   крупные слова-субтитры, это заметно держит досмотр. faster-whisper уже даёт тайминги слов.
7. ~~Ещё одна площадка: Whop Content Rewards~~. Отпадает (владелец, 26.11.2026): Whop и Vyro требуют паспорт
   и селфи. Работаем только с площадками без проверки личности: promote.fun (крипта), clipping.net.
8. **Аккаунты заранее одобрены в нишах** (кино, мемы): у promote.fun «Only movie niche pages will be accepted»,
   одобрение делает клиент и это долго. Значит аккаунты должны быть в кампаниях до того, как бюджет пошёл.

Вывод из clipper-bot: официальные API для постинга не подходят. TikTok без аудита приложения публикует только
приватно, YouTube без проверки проекта тоже приватно и ~6 загрузок в день. Значит наш путь через браузер AdsPower
правильный, его и ускоряем.

## Предлагаемый порядок

1. Горячий режим `campaign-go` + публикация без окон и пауз + параллельные браузеры (п. 1-2).
2. Кнопки в Telegram (п. 3).
3. Субтитры по словам (п. 6).
4. Автосабмит (п. 4), быстрая нарезка YouTube (п. 5).

## Сделано (26.11.2026)

- `python -m clips campaign-go <кампания> [--source файл_или_ссылка] [--approve]`: нарезка, хуки (с `--approve`
  без ожидания), план сразу на все аккаунты кампании (`hot_posts_per_account` постов, `hot_gap_minutes` между ними,
  без окна и дневного лимита), публикация немедленно, итог в Telegram.
- Публикация параллельно: `publish_workers` профилей AdsPower одновременно, у каждого профиля все его посты
  (TikTok, YouTube, X) за одну сессию браузера. Ошибка на одной платформе не мешает остальным.
